#  Rohaan — Creative Designer Portfolio

A whimsical, hand-drawn digital sketchbook portfolio built with HTML, CSS, and a touch of JavaScript. This project features a unique "paper and ink" aesthetic with organic animations and custom interactive elements.

## Design Concept
The goal of this project was to break away from the standard "clean and corporate" tech aesthetic. 
- **Paper Texture:** Uses CSS patterns to simulate real sketchbook paper.
- **Organic Movement:** Every element is slightly tilted or "imperfect" to give a handmade feel.
- **Custom Interaction:** Features a bespoke cursor and "marker-style" hover effects.

## Features
- **Interactive Cursor:** A custom-built circle and dot cursor that reacts to hover states.
- **Sketchbook UI:** Hand-drawn underlines, pinned project cards, and handwritten typography.
- **Marquee Skills Strip:** A dynamic scrolling ticker showcasing technical expertise.
- **Responsive Grid:** A playful portfolio grid that adjusts for mobile devices.

## Built With
- **HTML5:** Semantic structure for accessibility.
- **CSS3:** Custom properties (variables), Grid, Flexbox, and Keyframe animations.
- **JavaScript:** Light interaction for the custom cursor and background canvas effects.
